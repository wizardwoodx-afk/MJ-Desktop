MJ 13.0.1 — offline verification pack provenance
===================================================

Release identity: MJ 13.0.1 — "the INK retune: unknown minerals on black"
(the owner-review pass on 13.0.0; engine logic untouched). The owner
judged the 13.0.0 palette "common" (warm-black + gold reads as the default
premium template) and the surface still instrument-cramped. 13.0.1:

1. PALETTE ON TRUE BLACK. OBSIDIAN six -> INK six: ink (black #000000 +
   smoked apricot #C98A62, default), pitch (OLED black + dusty rose),
   slag (graphite + whetstone steel), fern (black-green + seedpod olive),
   ivory (paper + copper), travertine (stone + bronze-olive). No gold, no
   brass, no violet, no cyan, no neon. Every secondary token derived from
   five base hues with color-mix; old prefs (incl. all OBSIDIAN-era names)
   migrate deliberately via THEME_ALIASES.
2. PREMIUM FRAME (research-driven: whitespace + type hierarchy are the
   largest premium signals, not paint). Muted copy reads in Inter 12.5
   instead of 9-11px mono; cards 22x24 padding at 14px radius; page
   gutters 34x38; buttons/inputs 8px radius, accent focus rings, quiet
   press state; nav rail reads Inter 12.5 with active accent tick; the
   Settings Appearance card is a real picker - each theme option is a row
   with a live two-tone ground+signal swatch, name and descriptor.
3. ICONS - the clean cut. FOUNDRY facet chips removed; all 43 glyphs are a
   uniform 1.6-weight stroke, round caps and joins, no fills.
4. NODE ANATOMY V2. Cards carry live state on the frame: running/error/done
   tint the border and icon tile (running agent spine pulses, killed by
   prefers-reduced-motion); ports straddle the card edge so wires visibly
   land on their anchors; connected ports fill with the signal + soft ring;
   valid targets pulse; purpose clamps to two lines; meta footer is one
   quiet dot-separated line.
