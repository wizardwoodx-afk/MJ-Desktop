11.11.1 — the strategy loop becomes a genuine online experiment
---------------------------------------------------------------
The 11.11.0 review (9.7/10) caught that candidates were scored on runs executed
under the parent's parameters and that an unmeasured baseline lost to any real
candidate score. 11.11.1 rebuilds the loop as a causal chain:

  - nextRunStrategy() assigns which strategy version the next run executes BEFORE
    it starts (balanced alternation; ties to the candidate).
  - teamExecutor executes that version's parameters for real (serialExec flattens
    waves, reviewDepth adds a second review pass instruction, checkBias sets the
    web-evidence slice, lessonBudget caps ORG_LESSONS) and the report records the
    governing strategy id.
  - settlement appends each run under that id; each arm is scored ONLY on its own
    attributed runs (armScores); the baseline is continuously measured, never null.
  - MIN_TRIALS = 3 measured runs per arm before any verdict; adoption needs a
    strict margin > 0.05; TRIAL_CAP = 8 retires inconclusive; unattributed
    (pre-11.11.1) runs score for no arm; simulated runs still teach nothing.
  - skill evolution described accurately: procedural knowledge (node defs +
    briefing lines), human-approved, not new executable tools.
  - "AGI-grade autonomy" label retired until justified; the claim is the narrower,
    stronger one: remembers, experiments, keeps only measured improvement.

probe/selfEvolve.test.ts grew 34 -> 51 assertions incl. the causal chain:
candidate selected -> actually executed -> own results recorded -> evaluated on
those results -> adopted/retired with the numbers.

  evidence) and R2 (proof-carrying actions) plus causal retrieval and the
