===================================================

Release identity: MJ 12.2.0 — "provider precision on the Knowledge Forge"
(the 12.1.1 review's one remaining item, closed). The 9.85/10 review
confirmed every 12.1.1 fix and froze the release with one open item:
dataHandling: "provider" said content went to the harness's configured
provider but not WHICH provider — Anthropic, OpenAI, a local model, or an
enterprise proxy. 12.2.0 records providerInfo on every provider-bound
proposal: vendor (the harness's default when unconfigured, labeled as such
— claude->Anthropic, codex->OpenAI, gemini->Google, grok->xAI, qwen->Alibaba
Qwen, opencode->configurable), endpointClass cloud-default /
local-configured / unknown, and endpointBasis detected / user-declared /
not-visible, with the written reason on every record. Honest by
construction: MJ reports only what it can see — a host-supplied readEnv
probe (no override visible = cloud-default; loopback = local-configured;
any other override or invalid URL = unknown with its reason; a throwing
probe = not-visible), else the user's own declaration (user-declared),
else the truthful default unknown + not-visible with the reason written
(the Tauri renderer sees only PATH/searched/bins — MJ cannot read the
harness's endpoint override settings; it never pretends otherwise).
Mechanical paths keep providerInfo: null. The forge card gains an ENDPOINT
(you declaration) select and provider chips (vendor . class; unknown is
visually distinct and explains itself on hover).
