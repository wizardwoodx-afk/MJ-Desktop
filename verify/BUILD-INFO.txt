What this pack does NOT prove
  - It does not compile the Rust crate. No cargo toolchain was available in the
    environment that built this pack, so `cargo check`, `cargo test` and
    `cargo clippy -D warnings` are CI's report, not a claim made here.
  - It does not run TypeScript type-checking or the production web build; both
    need devDependencies (React types, the Tauri API surface), which is exactly
    why this pack exists — the runtime gate does not.
