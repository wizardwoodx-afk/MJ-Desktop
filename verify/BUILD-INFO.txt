11.14.5 — what changed over 11.14.3
-----------------------------------
The 11.14.5 audit's verdict: the engineering claims held (zero type escapes,
zero TODO markers, zero stray console output, zero Rust unsafe, zero npm
vulnerabilities), so this release turns the remaining gaps into product:

  1. PROBLEM-FIRST FOCUS. docs/PROBLEM-FOCUS.md is the reverse-index every
     feature must answer to: problem → feature → code → probe, built on the
     ipse-dixit market evidence (88% of agent pilots never reach production;
     92% of CISOs lack agent-identity visibility; EU AI Act enforcement wave,
     Aug 2026). The Home hero now states the problem MJ solves instead of
     describing its internals; README and CHANGELOG carry the same framing.
  2. PACKAGED-DESKTOP WEB EVIDENCE UNBLOCKED (bug). The production CSP's
     connect-src allowed no https: origin, so the Researcher's documented
     renderer-fetched providers (Wikipedia, HN Algolia, GitHub search, Brave)
     were silently blocked in the packaged desktop build. The CSP now
     allow-lists exactly those four hosts (plus the pre-existing local
     services) — no blanket https:, no new exfiltration surface.
  3. HYGIENE FLOOR MADE MECHANICAL. probe/codeHygiene.test.ts (13
     assertions): CI now fails on any future as any / @ts-ignore /
     @ts-nocheck, TODO/FIXME/HACK marker, stray console output, a second
     eval surface, CSP regressions (unset, unsafe-eval/inline in
     script-src, lost local-service or provider hosts), Rust unsafe, or an
     orphaned permission grant.
  4. CLEANUP. The updater:default capability was granted while the updater
     plugin had no endpoints, public key or updater artifacts and zero
     frontend callers — removed. src-tauri/Cargo.lock still named mj-desktop
     11.10.5 while every other manifest said 11.14.3 — aligned to 11.14.5;
     every manifest now agrees (versionDrift green).
