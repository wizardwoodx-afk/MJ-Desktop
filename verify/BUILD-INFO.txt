THE TRUST MODEL (the fix this release exists for)
  A signed artifact carries its own issuer public key; signature math alone can
  never prove that key belongs to MJ. Both standalone verifiers now require the
  issuer key to be pinned out-of-band:
    --issuer-key <hex64|@file>   match -> VALID, issuer AUTHENTICATED (exit 0)
                                 mismatch -> INVALID (exit 1)
    no pin -> VALID SIGNATURE, issuer UNVERIFIED (exit 3, fingerprint printed,
              never presented as authenticated)
  Claim language corrected everywhere: zero MJ state required, issuer key pinned
  out-of-band — never "zero trust required".

14.1.1 — upgrade notes
----------------------

     the fingerprint out-of-band once; exit 3 = integrity-valid, issuer unverified.

  3. INK palette hex values stay frozen (theme.test pins them); ATELIER is the
     component-layer refinement surface.
