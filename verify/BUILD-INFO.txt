MJ 13.5.1 — offline verification pack provenance
===================================================

Release identity: MJ 13.5.1 — "skill/implementation agreement" (the 13.5.0
review's one finding, closed; then the design system freezes). The 9.85/10
review (product-polish 10/10) flagged that skills/ui-motion-language said
"Animate only transform and opacity" while the NATURA CSS also transitions
paint properties (box-shadow, border-color, background, color, stroke) — a
shipped skill stricter than the implementation it documents. 13.5.1 takes
the reviewer's recommended option 1: the rule now reads LAYOUT MOTION USES
ONLY transform/opacity (never width/height/top/left/margin), while
VISUAL-STATE TRANSITIONS may also animate paint properties (short, <=200ms,
state not entrance). No CSS changed — the code was the correct nuanced
behavior; the documentation now says what the code does. The fix is
probe-pinned: meridian 45 -> 46/46 (the motion skill must keep the nuanced
rule and never regress to the absolute).

DESIGN FREEZE: with the skill aligned, the design system is frozen at the
INK six + NATURA material/motion + the three shipped design skills
(skills/ui-premium-craft, skills/ui-motion-language,
skills/node-graph-craft). Future UI work extends the frozen system through
the skills; it does not invent new palettes or motion languages. The
highest-value next work is real users, real repeated missions, real human
feedback, real evidence.
