11.12.1 — what changed over 11.12.0
-----------------------------------
Review fix 1 (9.75/10 review): the execution boundary is now fully
cryptographic. TeamExecutor calls verifyActionPacket (digest + Ed25519)
FIRST, aborts on any mismatch, and only then applies packetAllowsExecution.
The runtime now proves "this exact signed packet says this action is
allowed". Pinned by varkhaAlign §5 (source-order + tamper behaviour).

Review fix 2: this file. BUILD-INFO is regenerated from the certifying tree
and contains no stale provenance; historical notes live in docs/history/.

Varkha extracts (docs/VARKHA-COMPAT.md), all small and probe-pinned:
  - SCAR before PRECEDENT: lessonsForBriefing retrieves matching failure
    lessons first, then the rest (optimism-bias correction).
  - Write asymmetry: agent-inferred beliefs ABOUT THE USER start pending and
    brief only after human approval; user-stated preferences are immediate.
  - Attenuation: the report carries per-seat envelopes (role scope,
    write:worktree / read:review-snapshot, spend:capped-by-ledger) derived
    from the packet that permitted the run.
  - Step-repetition signal: identical consecutive turn signatures per seat
    (MAST's step repetition) surface as a SUGGEST-level Chamber signal, never
    auto-acted, never fed to the strategy experiment.
  - Ablation clarity: diffDims pins that every candidate — mosaic included —
    differs from its parent by exactly one dimension: each experiment is a
    paired toggle against the same parent configuration.

No new subsystems were added, per the review's advice; the next meaningful
proof is whether real developers get measurable value from 11.12.x.
