# MJ 11.0 — the final upgrade

**V11 is the last planned version.** The theme from every previous release note applies one
last time: MJ does not claim; MJ shows. This document is the release ledger — what was built,
what is *proven* by executable checks, and — just as important — what is **not proven** and how
to prove it on your machine, because the build that produced this source tree had no Rust
toolchain and no OS webview stack.

---

## What V11 is

The same app it has been since V1 — a local, human-supervised visual agent workstation — with
all seven proposal workstreams from `MJ-11.0-PROPOSAL.md` implemented:

## What is NOT proven — read this before you ship anything

1. **None of `src-tauri/` was compiled for V11.** The machine that produced this tree has no
   Rust toolchain, no GTK, no WebKitGTK. The V11 Rust (acp.rs, control_mcp.rs rework, db.rs
   schema + tools, command wiring, updater plugin) passed a line-by-line static review and
   nothing else. First thing to do:
   ```bash
   cd src-tauri && cargo check --all-targets && cargo test
   ```
   `control_mcp.rs` ships with its own `cargo test` units (in-memory SQLite through the shipped
   schema); they are designed to run exactly where the code will run.
2. **The updater is wired but inert** until you do the release setup: generate a minisign key
   (`npm run tauri signer generate`), put the private key in GitHub secrets
   (`TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`), paste the public key
   into `src-tauri/tauri.conf.json → plugins.updater.pubkey`, and point
   `plugins.updater.endpoints` at your repository's `latest.json`. Untagged builds simply never
   check for updates.
3. **Sandbox enforcement is platform-conditional.** Linux needs `bubblewrap` installed;
   macOS uses `sandbox-exec`; Windows honestly reports "no native wrapper — run under WSL2".
   The Proof page says which seats were *measured* and which were merely *profiled*.
4. **W7 A2A is fenced off.** Card reading works; task invocation does not exist in V11, by
   decision, and the fence says so at runtime.

## Install it natively (this is the only supported install)

MJ is a Tauri desktop app. There is no hosted mode; the browser preview in this repository is
a development artifact only. Full prerequisites and per-OS commands are in
**`INSTALL-ON-LAPTOP.md`** (short version: Node 20, Rust stable, per-OS WebKit/GTK dev
packages, then `npm ci && npm run tauri build` — the signed installer appears in
`src-tauri/target/release/bundle/`).

## Run every check yourself

```bash
npm ci
./node_modules/.bin/tsc --noEmit
for f in versionDrift acceptance harnessPolicy checkRunner engine replayEvals theme assist \
         acp agentsMd otelExport controlPlane stubLedger sandbox a2a; do
  ./node_modules/.bin/esbuild probe/$f.test.ts --bundle --platform=node --format=esm \
    --define:MJ_ROOT='"'$(pwd)'"' --outfile=probe/.$f.mjs --log-level=error
  node probe/.$f.mjs || exit 1
done
cd src-tauri && cargo test && cd ..
```

### From 10.1 → 11.0, for the record

- Assist no longer guesses at providers (root cause: provider resolution read a config slot
  that was never written; V11 resolves from attached cloud refs, then Ollama, and says which).
- Themes: +3 (nord, solar, hermes); `nothing` refined to true-black per Nothing OS 3/4 design
  language; theme whitelist enforced in all three registration sites by probe.
- `db.open()` now runs a tested `init()` + an idempotent migration, so old databases upgrade
  in place.
- Every advertised MCP control tool is implemented; the execution-state tools were removed
  from the advertisement rather than faked.
- CI and the signed release pipeline exist; the "cargo check has never run" line in the
  honesty ledger is retired the first time CI goes green on your fork.

**No further upgrades are planned.** If a bug is found after this release, the fix should come
with a probe in the same commit — that has been the rule since V6, and it is what makes this
the last version instead of just the last one anyone bothered to test.
