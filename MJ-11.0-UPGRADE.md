## 🚀 Key Systems in this Release

### 1. Real-Time Inter-Agent Message Bus & Shared Blackboard (`src/mission/interAgentChannel.ts`)
- **Pub/Sub Channels**: `#general`, `#architecture`, `#implementation-sync`, `#qa-review`, `#security-audit`.
- **Targeted Mentions**: `@coder`, `@reviewer`, `@architect`, `@all`.
- **Typed Message Intents**: `proposal`, `contract`, `blocker`, `handoff`, `verification`, `operator`, `broadcast`.
- **Threaded Replies & Sequences**: Full support for hierarchical parent-child discussions and message threading.
- **Shared Blackboard State**: Synchronized key-value contract store with automatic versioning (`v1`, `v2`, `v3`) and reactive subscription callbacks.
- **Engine Integration**: Connected directly into `teamExecutor.ts` and `TeamsPage.tsx` — real child processes stream worktree commits and review verdicts to the bus in real time.

### 2. Expanded 14-Harness Coding CLI Registry
1. **Claude Code** (`claude`): Read-only enforcement via permission mode & structured JSON streaming.
2. **OpenAI Codex CLI** (`codex`): Sandboxed `--sandbox workspace-write` execution.
3. **OpenCode AI** (`opencode`): Multi-model local agent runner.
4. **Cursor Agent** (`cursor-agent`): Fast prompt-based workspace reasoning.
5. **Aider AI** (`aider`): Non-interactive `--message --yes --no-auto-commits` git pair programmer.
6. **Google Gemini CLI** (`gemini`): Plan Mode `--approval-mode plan` with Google authentication.
7. **Goose CLI** (`goose`): MCP-extensible agent running `goose run --text`.
8. **Amazon Q / Kiro CLI** (`kiro-cli` / `amazonq`): AWS enterprise compliance agent running `chat --no-interactive`.
9. **xAI Grok CLI** (`grok`): Fast reasoning with `-p` headless invocation.
10. **Cline CLI** (`cline`): Direct prompt executor with Plan/Act safety gates.
11. **Alibaba Qwen Code** (`qwen`): Multilingual code generation via `qwen -p`.
12. **Kilo Code** (`kilo`): Offline refactoring CLI.
13. **Hermes Agent** (`hermes`): Function-calling open model runtime.
14. **ACP Protocol** (`acp`): Agent Client Protocol standard JSON-RPC 2.0 handshake.

### 3. Git Worktree & Review Snapshot Isolation
- **Private Worktrees**: Every writer executes in an isolated sibling worktree (`mj/<mission>/<seat>`).
- **Detached Review Snapshots**: Reviewers NEVER inspect the pristine base checkout while work is in progress. Instead, writers' branches are merged with `--no-ff` into a temporary review snapshot branch (`mj/<mission>/review`), and reviewers inspect that snapshot.
- **Git-Excluded Briefings**: Agent instructions and task requirements are injected via `.mj-brief/` and registered in `.git/info/exclude` to prevent accidental commits.
