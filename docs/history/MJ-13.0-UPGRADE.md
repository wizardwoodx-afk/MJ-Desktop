# MJ 13 — UPGRADE notes (the production-surface finish)

This file exists per the probe contract (theme probe: every `MJ-x.y` ships
`MJ-x.y-UPGRADE.md`). Full notes live in `CHANGELOG.md` row 13.0.0,
`docs/history/MJ-13.0.0-POINTER.md`, and the module headers of
`src/styles/themes.css` + `src/styles/redesign.css`.

## What 13.0 is

A **major UI/UX upgrade release**: the frozen 12.x engine underneath is
untouched; the entire visual surface ships as the OBSIDIAN system — a
"production finish" built to the 2026 calm-tech direction. The engine's
honesty rules, approval gates, probes and architecture are unchanged.

## What changed for the user

1. **Brand-new themes** — the fourteen INSCRIBED palettes are retired for six
   finished palettes (old saved preferences migrate automatically):
   - `obsidian` — the flagship dark (new default): warm-jet ground, parchment
     ink, **brass** signal.
   - `onyx` — OLED black, champagne signal.
   - `hematite` — cool graphite, verdigris signal.
   - `peat` — botanical black-green, clay signal.
   - `ivory` — warm-paper light flagship, copper signal.
   - `travertine` — warm-stone light, bronze-olive signal.
   Every palette derives its secondaries from five base hues with
   `color-mix`; no gradients, no violet/cyan AI neon anywhere; the data-type
   wire colours were retuned to the same mineral voice (steel / moss / bronze
   / ochre / slate / bone).
2. **A new node concept** — node cards are precision plates: the head icon
   rides a **tile**, a category **spine** runs down the left edge (signal for
   agents/controls, quiet ink for text/gates/tools), the **state lamp**
   breathes while a node runs and goes quiet under `prefers-reduced-motion`,
   purpose and stream previews are framed, and meta chips read like
   instrument tags.
3. **Port ↔ wire connection clarity** — ports are type-coloured rings that
   fill with the graph signal when connected; every anchor carries a short
   **reach stub** across the card edge so the wire visually *joins* the port;
   valid drop targets **pulse** while a ghost wire is out; wires are thicker
   and brighten on hover with a soft glow.
4. **More premium motion** — view entrances, panel slides, port pulses and
   lamp breathing are tuned to 140–280ms purposeful ease-out; every animation
   is transform/opacity only and dies under `prefers-reduced-motion`.
5. **Assist is removed** (owner decision) — the sidebar item, Ctrl/Cmd+J,
   the canvas console button and the panel are gone; the canvas-only mount
   bug that made it appear broken on every other page is moot. The honest
   custom-node path (Home page field + offline drafts via `customNode`) stays.

# MJ 13.0.1 — patch notes (appended to the 13.0 upgrade record)

The owner review of 13.0.0: the palette read "common" (warm-black + gold is
the default premium template) and the surface still felt like an engineering
tool — cramped, mono-shouting, nodes restyled rather than redesigned.
13.0.1 is the INK retune:

1. **Palette** — OBSIDIAN six → INK six on TRUE BLACK: `ink` (smoked
   apricot, default), `pitch` (OLED, dusty rose), `slag` (whetstone), `fern`
   (seedpod olive), `ivory`/`travertine` paper lights. No gold/brass/
   violet/cyan; old themes migrate by alias.
2. **Premium frame** — muted copy reads in Inter (not 9px mono), cards and
   page gutters grow, buttons/inputs get 8px radius + accent focus ring, the
   rail reads in Inter 12.5 with an active tick, Settings theme options show
   live two-tone previews.
3. **Icons** — the clean cut: 1.6-weight uniform strokes, round joins, no
   facet chips, no fills (43 glyphs).
4. **Nodes anatomy v2** — live state on the border + icon tile, running
   spine pulse (reduced-motion safe), ports straddle the card edge so wires
   land visibly, connected ports fill with a soft ring, purpose clamps to
   two lines, meta becomes one dot-separated line.

Probes: theme.test 61 → **64/64** (reads THEME_IDS from store.ts; ink-set
hue pins, black-ground proof, no-gold ban, alias migration), meridian 42/42
with the icon-cut pins. Engine suites untouched: missionLoop 80/80,
knowledgeSkills 56/56, navAlign 42/42.
