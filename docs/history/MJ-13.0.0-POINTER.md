# MJ 13.0.0 — the production-surface finish (OBSIDIAN)

*Release pointer. Full notes live in the CHANGELOG row (13.0.0); this file
names what changed and where.*

## 1. What this release is

A major UI/UX upgrade on the frozen 12.x engine: **the OBSIDIAN design
system**, six finished palettes built to the 2026 calm-tech direction —
warm elevated neutrals as the ground, ONE rare mineral signal per theme
(brass, champagne, verdigris, clay, copper, bronze-olive), and no AI-violet
or cyan neon anywhere. Old saved themes migrate deliberately (wabi→obsidian,
inscribed→onyx, carbon/cyanotype→hematite, daylight/chalk→ivory, …).

## 3. The new node concept + connection language

- Node cards = precision plates: icon **tile** on the head, category
  **spine** on the left edge, breathing **state lamp**, framed purpose and
  stream previews, instrument **meta chips**.
- Ports: type-coloured rings that **fill with the graph signal when
  connected**; **reach stubs** carry the anchor across the card edge so a
  wire visually joins its port; valid targets **pulse** while linking.
- Wires: thicker presence, hover glow via the existing mj-glow filter,
  status widths (active/streaming/error/completed).
- Motion: 140–280ms ease-out on transform/opacity only; every animation
  honours `prefers-reduced-motion` (verified by probes).

## 4. Assist removed (owner decision)

The assistant panel never mounted outside the canvas page — on every other
page its buttons silently did nothing. Per the owner's instruction Assist is
removed entirely (nav item, Ctrl/Cmd+J, console button, panel, CSS). The
honest one-node drafting path (Home page + offline-labelled drafts) remains.
