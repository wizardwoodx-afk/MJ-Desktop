# MJ 11.13 — Upgrade notes

## MJ 11.13.0 (this release) — the Differentiators

Market context first (2026): coding agents compete on benchmarks and inline
UX, while enterprises say off-the-shelf copilots lack "reliability,
auditability and policy control", and governance vendors sell "policy-to-proof"
as their headline. MJ's claim is the defensible one: it COMBINES agent-team
authority, verification, learning evidence and proof export in one local
execution system. MJ already held the primitives; 11.13.0
makes them enforced product features:

1. **Budget authority.** The root envelope carries `budgetUsd` — signed into
   the canonical digest, attenuated like every other power (children may
   tighten the cap, never loosen it), refused pre-flight when already
   exhausted, and checked by the executor against REAL charged spend after
   every wave: no further seat is invoked once the cap is crossed. The runner
   UI exposes the cap; blank = uncapped.
2. **Proof dossier** (`src/mission/dossier.ts`). One click on the Audit page
   exports a single digest-stamped JSON: memories, beliefs, skills, the
   measured experiment, receipts and the live ledger — all derived from the
   stores at export time. Any edit after export breaks the digest
   (`verifyProofDossier`).
3. **Proof-of-learning** rides inside the dossier: strategy versions, adopted
   score and note, measured-run count.

Also: Settings says fourteen palettes (the 9.8/10 review's nit); 11.12.4 was
intentionally skipped — 11.12.5 followed 11.12.3 directly, and this feature
release opens 11.13.x.

New probe: differentiatorAlign (16 assertions). Counts: 64 live suites /
63 offline bundles. Gates on Node v22.23.2: tsc 0, 64/64 live, 63/63 offline,
vite 0.

The architecture from 11.12.x is unchanged — this release turns governance
into product: what MJ can spend, what it can prove, and what it has learned.

## MJ 11.13.1 (this point release) — hard-cap honesty + adopted patterns

The 9.6/10 review named one flaw: the budget cap was not atomic across a
concurrent wave. Fixed exactly as prescribed:

1. **Atomic budget admission.** A `BudgetGate` (custody.ts) makes every
   concurrent seat RESERVE its share of the remaining cap BEFORE dispatch —
   the check-and-commit holds no await, so parallel seats cannot double-spend
   the same remainder. Seats the cap cannot admit are refused with the real
   reason; after the wave, each reservation is settled against the REAL
   charge and any per-seat overrun is measured, named and reported — never
   hidden. The guarantee MJ now makes: committed spend at dispatch time can
   never cross the cap; overshoot by a lying cost report is measured at
   settlement, not prevented.
2. **Token-only honesty.** Harnesses that report tokens but no dollars are
   marked dollar-UNKNOWN in the run report and budget accounting. USD
   reported → enforceable; tokens only → spend in USD unknown. MJ never
   invents a price.
3. **Dossier described correctly.** Digest-stamped = tamper-evident from the
   moment of export; not independently issuer-signed. The Ed25519 signatures
   live on the learning receipts inside it.
4. **Market claim toned down.** MJ's claim is the defensible combination —
   agent-team authority + verification + learning evidence + proof export in
   one local execution system.

Two new capabilities, adopted from public agent systems as PATTERNS, never
code (provenance on every entry: observed source + license of the observed
project + "no code copied"):

5. **Pattern Registry** (`src/mission/patterns.ts`): sub-agent orchestration
   (OpenHands/SWE-agent, MIT), tool-calling registries (Goose/MCP, Apache
   2.0), and from Anthropic's Apache-2.0 Claude Commerce Agents blueprint —
   code-level guardrails, approval staging, dynamic skill loading vs agent
   splitting (MJ keeps both and lets the experiment measure which wins), and
   cost honesty (Codex/OpenCode). Any pattern can be proposed into the normal
   human-approval skill queue — agents propose, humans install.
6. **Guardrail Manifest** (Audit page): the ten rules MJ physically cannot
   break, each pinned as a running code check by probe/guardrailAlign.

New probes: guardrailAlign (10), patternAlign (9); differentiatorAlign
16 -> 22 (atomic reservation, token-only wording). Counts: 66 live suites /
65 offline bundles. Gates on Node v22.23.2: tsc 0, 66/66 live, 65/65 offline,
vite 0.
