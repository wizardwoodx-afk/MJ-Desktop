# MJ 11.14.5 — THE FOCUSED RELEASE (problem-first) (2026-09-07)

> 11.14.3 survived a hostile external audit — every engineering claim held.
> So 11.14.5 stops describing the machine and starts naming the problem:
> MJ exists because companies cannot prove what their agents did, who
> approved it, that an independent agent checked it, and that data never
> left the laptop.

## What landed (over 11.14.3)

- **Problem-first doctrine.** `docs/PROBLEM-FOCUS.md` is the reverse-index
  every feature must answer — problem → feature → code → probe — built on
  market evidence (88% of enterprise agent pilots never reach production;
  92% of CISOs lack agent-identity visibility; the EU AI Act high-risk
  enforcement wave began August 2026). The Home hero now opens with the
  problem, then the answer; README and CHANGELOG carry the same framing.
- **Packaged-desktop bug fixed.** The native build's CSP allowed no `https:`
  in `connect-src`, so the Researcher's renderer-fetched web-evidence
  providers (Wikipedia, HN Algolia, GitHub search, Brave) were silently
  blocked in the desktop app. CSP now allow-lists exactly those four hosts
  plus the pre-existing local services — no blanket `https:`.
- **Hygiene floor made mechanical.** `probe/codeHygiene.test.ts` (13
  assertions): CI fails on any future `as any` / `@ts-ignore` /
  `@ts-nocheck`, TODO/FIXME marker, stray console output, second eval
  surface, CSP regression, Rust `unsafe`, or orphaned permission grant.
- **Cleanup.** Orphaned `updater:default` grant removed (no endpoints,
  public key, updater artifacts or callers). `Cargo.lock`'s stale
  `mj-desktop 11.10.5` aligned to 11.14.5 — every manifest now agrees.
