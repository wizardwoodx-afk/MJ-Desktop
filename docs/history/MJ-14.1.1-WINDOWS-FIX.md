# MJ 14.1.1 — Windows fix + cleanup (what differs from the zip)

> This tree is 14.1.1 **plus the fixes below**. The `v14.1.1` tag was re-cut
> on top of the shipped source so the app a pre-seed demo installs actually
> runs. Nothing else was touched: to verify, diff the tag against
> `MJ-14.1.1-source.zip` — every difference is listed here, file by file.
> (Same procedure previously applied to 13.5.1 — see
> `docs/history/MJ-13.5.1-WINDOWS-FIX.md`.)

## Code fixes

1. **`src-tauri/src/lib.rs` — updater plugin init removed.**
   `tauri_plugin_updater::Builder::new().build()` with `"plugins": {}` in
   `tauri.conf.json` is a fatal `PluginInitialization` error: every desktop
   build exited 101 before setup (no window, no data dir, no log — silent in
   release because the release profile sets `panic = "abort"`). Reproduced on
   the shipped 14.1.1 tree with a console build before fixing. The updater has
   no endpoints, no pubkey, no artifacts and zero callers, so the init line
   goes; updates remain "download the new zip and reinstall".
2. **`src-tauri/Cargo.toml` — `tauri-plugin-updater = "2"` dependency removed**
   (orphaned by fix 1; `Cargo.lock` regenerated by the build).
3. **`probe/twoNodeAlign.test.ts` — leak-check made boundary-aware.**
   Bare `seen.includes(v)` false-fired on ISO `computedAt` timestamps
   (`...24.185Z` contains `4.1`) in ~1% of runs. The check now requires digit
   boundaries around each raw value — strictly stronger against real leaks,
   immune to timestamps. Proven 50/50 clean under repetition on this tree.
4. **`verify/suites/*` + `verify/MANIFEST.json` — offline pack rebuilt** from
   the fixed probe via `tools/build-offline-verify.mjs` (the offlinePack
   freshness gate passes: rebuild == shipped).

## CI: Windows-only

- **`.github/workflows/release.yml`** — macOS/Linux matrix entries and the
  Linux system-deps step removed; signing env removed (nothing to sign
  without an updater); added a Rust-tests step and a **launch smoke step**
  (starts the built exe, fails the run if it exits within 25s — the exact
  gate whose absence shipped dead apps).
- **`.github/workflows/ci.yml`** — cut to `windows-latest` (kept: git
  identity, watchdog headroom, probe-log upload).
- **`src-tauri/tauri.conf.json`** — bundle targets cut to `["nsis"]`;
  macOS/Linux bundle sections removed.
