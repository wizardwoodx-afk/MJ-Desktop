# MJ 11.14.7 — THE ARENA GATE (hostile battery before real runs) (2026-09-07)

> 2026 enterprise practice made the arena a deployment gate (Lakera, Promptfoo,
> PyRIT, Giskard; OWASP Agentic Top-10). MJ's answer is not another LLM
> red-teaming SaaS — it is a battery that attacks MJ's OWN governance machine
> and refuses to bless a mission until every boundary holds in words.
>
> `guardrailAlign` asserts the SOURCE contains the right markers; the Arena
> Gate EXECUTES the real modules with hostile inputs and checks the refusal
> actually happens. Guardrails-as-code became guardrails-as-executable-battery.

## What landed (over 11.14.5)

- **`src/mission/arenaGate.ts`** — `runGovernanceArena()` runs 11 hostile
  scenarios against the real custody / capability / egress / verifyGate /
  ledger modules:
  `arena.self-grading` (the writer verifies its own work),
  `arena.agent-root` (an agent obtains a root envelope),
  `arena.scope-growth` (attenuation widens the parent's scope),
  `arena.expiry` / `arena.revocation` (lapsed / kill-switched envelopes),
  `arena.budget-cap` / `arena.budget-race` (hard caps + atomic reservations),
  `arena.egress-scope` (compute authority exfiltrates a file),
  `arena.tamper` (post-signing edits still fail verification),
  `arena.ledger-write` (an agent writes DOCTRINE),
  `arena.capability-policy` (aggregates over datasets this machine does not
  expose).
  Every outcome is a refusal IN WORDS; any breach → gate **REFUSED**, naming
  the scenario. The report carries a canonical sha256 `digest` attachable to
  receipts, and a fixed default clock keeps the battery deterministic.
- **`probe/arenaGate.test.ts`** (22 assertions) — pins every scenario
  defended, refusals named, digest stability across runs.
- Counts: 71 live suites / 70 offline bundles.

## Honest scope

The battery attacks MJ's mechanical policy boundaries — the surfaces where MJ
promises hard guarantees. It is not (yet) an LLM red-team that fuzzes prompts
through live harnesses; that needs real seats and is a UI/harness milestone,
documented in `docs/DIFFERENTIATOR-ROADMAP.md` as the arena's next layer.
UI surfacing of the gate (a pre-flight card on mission planning, report in the
receipt vault) is likewise queued behind a browser-verifiable step.
