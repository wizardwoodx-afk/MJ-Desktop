# MJ 14.1.2 — EXTERNAL-REVIEW HARDENING (2026-09-09)

> Two findings from the independent 14.1.1 review (9.2/10, "strongest MJ
> version so far"), both fixed and probe-pinned, plus the premium roadmap.

The 14.1.2 upgrade notes ship in upstream `verify/BUILD-INFO.txt`. This file
is the discoverable pointer in-repo.

## What landed (over 14.1.1)

- **Version integrity.** `missionRecord.ts` carried a stale hardcoded
  "14.1.0" in the record's `mjVersion` while the drift gate never scanned
  the file. The record now imports `MJ_VERSION`, and `versionDrift` grew to
  42/42 scanning the crown artifact (imports `MJ_VERSION`; no hardcoded
  release literals).
- **Hostile-input robustness.** Garbage issuer keys produced raw OpenSSL
  stack traces in the standalone verifiers. Both now answer
  "INVALID: malformed issuer public key (expected 64 hex chars)" (exit 1).
- **`docs/PREMIUM-ROADMAP.md`** added; README bundle count corrected.

## Known issues (upstream, unpatched — verified in-tree)

1. **Desktop build cannot launch** (`src-tauri/src/lib.rs:32`, updater init
   with empty config — exit 101). Fixed in the 13.5.1/14.1.1 Windows-fix
   trees; not yet adopted upstream.
2. **`loopBusFeed` detached subscribe crashes every LoopPage mount**
   (`reading 'add'`). Proven with stack trace in a real browser; one-line
   closure fix verified (all five pages render, 0 errors). Fix sits
   uncommitted in the 14.1.1-fix workdir, not yet on GitHub.
3. **`twoNodeAlign` leak-check flake (~1%)** — timestamp collision, product
   clean. Boundary-aware fix proven; not yet adopted upstream.
