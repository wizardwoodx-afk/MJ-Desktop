## What landed

- **Trust-anchor fix.** Both standalone verifiers (`tools/verify-receipt.mjs`,
  `tools/verify-mission-record.mjs`) require `--issuer-key` pinning:
  match → VALID + AUTHENTICATED (exit 0); mismatch → INVALID (exit 1);
  no pin → VALID SIGNATURE but UNVERIFIED issuer (exit 3, fingerprint
  printed). Claim language corrected everywhere: "zero MJ state, issuer key
  pinned out-of-band" — never "zero trust required".
- **Mission-complete economics.** Per-cycle rows (exact CSV derivation) +
  totals across the record; Audit-page sealer.
- **Three Audit products** (`evidenceSurfaces`), **finOps**, **assuranceScore**,
  **incidentDossier**, ATELIER precision layer, OS-keychain issuer key,
  CI watchdog + probe-log artifacts.
