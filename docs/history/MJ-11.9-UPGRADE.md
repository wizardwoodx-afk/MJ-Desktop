# MJ 11.9 — NTH VISUAL SYSTEM + CANVAS INTEGRITY

> One release, three parts: the app is **de-vendored**, painted in the new **NTH** palette, and
> the **canvas** gets the fixes that made wires and ports behave. Bumped `11.9.0` across every
> manifest so it can be shipped as a single upgrade.

## 0. De-vendored

Removed `vendor/hermes-agent` + `vendor/hermes-agent-self-evolution` (~633 files / ~12 MB).
MJ never executed that code — it was only a path constant, an unused env var and comments. The
SKILL.md contract, parsing, and evolution fitness/constraints engine are MJ's own TypeScript.
`NOTICE`/`VENDOR.md` updated; only the two runtime MCP server sets remain vendored (and credited).

## 1. NTH theme (default)

One design system, five rare colours, **zero brown**:

| Token | Colour | Role |
|---|---|---|
| `void` | `#05060b` | obsidian ground |
| `ink` | `#f2f5fb` | primary text |

A single functional red (`#ff3d6e`) is reserved for errors only — never a brand colour. `nth` is

## 2. Canvas fixes

- **Wires connect to ports.** Port geometry is now measured from **rendered bounding boxes**
  (anchor rect − card rect, divided by zoom) instead of an `offsetTop` walk — which was off by
  ~6px and grew per row, detaching wires from the ports. Wires re-measure after every node
  drag/drop/connect (a `requestAnimationFrame(invalidatePortMetrics)` on graph change), so a moved
  node's wires re-anchor to the port a human can see.
- **Overlapping nodes stay clean.** Each `.node-card` is now an isolated stacking context
  (`isolation: isolate`) with an explicit `z-index`, and the selected/dragged node lifts to the
  top — so an overlapping node never exposes the behind node's ports.
- **Ports sit inside the card edge** (moved off `margin: -6px` to a proper inset) and glow on
  hover/valid-target so the connection target is unmistakable.
- **Node sizing** is one source of truth (`NODE_W`), and the pre-measure fallback now tracks the
  real first-port offset. **Minimap** keeps its own clear corner.

## §7 — 11.9.3: the NTH theme actually renders (UI/UX audit catch)

The owner asked for a real UI/UX change; a live screenshot audit showed **none** — the app
was visually identical to the pre-NTH red release even with the NTH chip selected.

Root cause was a CSS cascade tie, not a missing theme. `mj.css` opens with a `:root { ... }`
fallback palette (the inscribed red/black) — specificity **0,1,0**. The `@import "./themes.css"`
is hoisted to the top of `mj.css`, so the `[data-theme="…"]` palette blocks (also **0,1,0**)
came **earlier** in source order. Equal specificity, later source wins → every theme, including
NTH, silently rendered the inscribed fallback. The selected "NTH" chip was a lie.

Fix: pin the fallback to **zero specificity** with `:where(:root)`, so any `[data-theme="…"]`
block always wins the cascade. Verified on a live render: all 12 NTH tokens now resolve
correctly (volt `#7c5cff` accent, obsidian `#05060b` ground, plasma `#2be6d6` pulse), and the
buttons, rail, chips and focus rings all render violet. This is the visible NTH UI the user asked for.

## §8 — 11.9.4: the FOUNDRY redesign (frontend-only)

The owner sent the v3 "Domain Color Atlas" and asked for a real frontend upgrade:
"use any 5 colors and change the icons… don't change the backend." The previous
releases genuinely changed the look (11.9.3 made NTH render at all) but it was still the
cold obsidian/violet identity — read as "similar." So the flagship was **re-cut**, not
recolored:

- **New identity (5 rare tones, no neon):** carbon ground `#0e0f0e`, cream ink `#f3eee3`,
  brass accent `#b8a17b`, verdigris "alive" pulse `#7ba58e`, and a functional oxide
  `#c0563f` reserved for errors. The `:root` boot-fallback was re-based to the same set.
- **A serif display voice:** `--font-serif` (Georgia) drives the `MJ.` wordmark, the hero
  headline, and every panel page title — the atlas's editorial "archive/foundry" tone.
- **Redrawn icon set:** the FOUNDRY cut — heavier 1.9 engraved stroke, miter joins, and a
  small filled *facet chip* at each glyph's junction (replacing the old round LED dot).
  The active rail item gets a brass plate marker + corner facet.
- **Backend untouched.** No graph/engine/ipc logic changed; only `themes.css`, `mj.css`,
  `canvas/icons.tsx`, Settings copy, and the two design probes, which now assert the new
  palette and the FOUNDRY icon grammar.
