## What landed (over 11.14.7)

- **`executeTeam` preflight (src/mission/teamExecutor.ts).** The governance
  arena runs BEFORE any seat is invoked — after custody / budget /
  action-packet admission, in the same refusal style: a REFUSED gate aborts
  the mission (`status: "aborted"`, "Nothing executed, nothing spent").
  `TeamRunReport.arena` stamps gate + canonical sha256 digest +
  defended/total/breached on every path (early aborts and the main return).
  `TeamRunnerDeps.arenaRunner` is the injection seam (tests inject a REFUSED
  battery to prove the refusal path).
- **The digest rides the real receipt (src/mission/receipts.ts).**
  `AutonomyRunSummary.arenaGate` → `buildProofReceipt` emits an `arena.gate`
  event (gate, digest, defended, total, summary) into the sealed SHA-256
  chain. Summaries without the stamp keep the pre-11.14.8 event shape
  exactly — the conditional event preserves older receipts byte-for-byte.
  TeamsPage's two receipt-issue sites pass the stamp through.
- **Review nits closed (src/mission/arenaGate.ts).** The exception
  classifier only counts MJ's typed module-prefixed refusals
  (`custody:`/`ledger:`/`capability:`/`egress:` + refusal language) as
  defended — never stray wording in an unrelated error. The canonical digest
  now covers id + title + outcome; refusal notes stay in the report and the
  receipt event as human-readable evidence. (Raw notes are deliberately NOT
  hashed: envelope ids embed a process-global sequence counter, which would
  make the stamp unreproducible — and reproducibility is what a receipt
  digest is for. Stated in code.)
- **New probe `arenaWired` (15 assertions).** Mission path carries the PASS
  stamp with the same digest as the standalone battery at one fixed clock; a
  REFUSED battery aborts before dispatch with nothing executed or spent; the
  sealed receipt chain carries the arena.gate event with the mission digest;
  legacy summaries keep their old shape.
