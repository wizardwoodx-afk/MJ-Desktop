# MJ 11.14.10 — THE CONSOLIDATION RELEASE (one product, one spine) (2026-09-07)

> Before 11.14.10, the app read like fourteen mini-apps stapled together:
> each destination had grown in its own release with its own nickname and its
> own corner of the sidebar. 11.14.10 makes MJ ONE product with ONE spine —
> Overview → Build → Run → Verify → Learn → System — and every feature
> belongs to exactly one stage of it.

## What landed (over 11.14.8)

- **`src/app/nav.ts` — the navigation single source of truth.** Every
  destination: stable key (a PageKind), purpose-clear public label
  (Workflows, Mission Control, Connectors — Canvas/Control/MCP retired),
  icon, one-line purpose. Groups are the six lifecycle stages in order.
- **`src/App.tsx` renders ONLY from the map** — the two ad-hoc arrays are
  gone; the render loop, keys, Ctrl+B collapse and aria-current behaviour
  are unchanged. Sidebar tooltips now state each destination's purpose.
- **`probe/navAlign.test.ts` (30 assertions)** — the consolidation made
  mechanical: every PageKind has exactly one nav entry (an orphan page is a
  product decision nobody made), groups are the canonical lifecycle in
  order, labels match the public vocabulary (no legacy mini-app names),
  App.tsx cannot fork its own nav again, and the Home hero speaks the same
  pillar language the spine is built on (verification, learning from
  feedback, local data, signed evidence).
- **`docs/INFORMATION-ARCHITECTURE.md`** — the model: the spine, the
  six-group destination table with purposes, the legacy→public rename
  table, the researched 2026 IA principles applied (content-first IA,
  clear labeling, agent-UX accountability surfaces), and the rule for
  future releases.

## Honest scope

Navigation keys, page components and the canvas/tab behaviour are
unchanged — this release aligns the product's public model, not its
internals. Page-level copy still carries older vocabulary in places
(the IA doc is the canonical map; copy harmonization continues release by
release). Counts: 73 live suites / 72 offline bundles.
