# MJ 12.0.3 — Rating scope (the architecture freeze point)

*Release pointer. Full notes live in the CHANGELOG row (12.0.3); this file
names what changed and where.*

## Why 12.0.3 exists

The 12.0.2 review (9.9/10) had exactly one remaining item: the feedback API
checked rating validity, cycle existence, team binding and seat records — but
not that the cycle actually RAN. ChatGPT assumed the UI only presents the
rating surface on completed cycles; in this tree the ledger shows the rating
panel on EVERY cycle row, so the invariant is user-reachable, not pure API.

## What changed

`submitHumanFeedback()` (`src/mission/missionLoop.ts`) now refuses an ABORTED
cycle outright, before any store write:

> `cycle <id> aborted before any seat ran — nothing to rate`

A gate-FAIL / blocked cycle whose seats DID run stays ratable, by design:
humans rate exactly the runs that went wrong. Aborted cycles execute nothing
(no seats, no verdict) — feedback on them would be pretend.

## Probes

`probe/missionLoop.test.ts` — 76 → **80/80**. The new rating-scope arc:
- an aborted cycle is produced through the engine's OWN exception path (an
  emit that throws once → the loop records status `aborted`, zero seat
  outcomes);
- rating it is refused with the explicit aborted message;
- the refusal leaves the evolution store byte-identical and the loop state
  untouched (no feedback entry);
- a gate-FAIL cycle with real seat outcomes rates cleanly, its queue entry
  landing for the next fold.

`probe/teamEvolution.test.ts` 48/48, `probe/navAlign.test.ts` 39/39 —
unchanged.

## Freeze

The 12.0 architecture is now locked: one canonical orchestrator over the
engines of record, one loop ledger, one product API, five doors, human
feedback bound to the team, supersede-safe per run, and scoped to cycles
that actually ran. The next release is the real-world evidence program —
repeated runs with real crews, measuring whether the loop's adaptations
change verified behavior over time — which cannot be faked in a sandbox and
must be built for the laptop and run there.
