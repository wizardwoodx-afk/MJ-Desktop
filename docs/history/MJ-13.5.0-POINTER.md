*Release pointer. Full notes live in the CHANGELOG row (13.5.0); this file
names what changed and where.*

## 1. Design skills ship in the repo (new)

`skills/` now carries three spec-form skills (frontmatter `name` +
`description` with what-and-when triggers, body < 500 lines):

- `ui-premium-craft` — the visual-system doctrine (whitespace as strategy,
  type hierarchy, restraint, color-as-state, warmth on black).
- `ui-motion-language` — the motion vocabulary (timing 120–320ms, natural
  deceleration easing, transform/opacity only, reduced-motion as law).
- `node-graph-craft` — the canvas connection language (node anatomy, ports
  on the edge, wire joins, the evaluation checklist).

They are loadable by any agent runtime and by MJ itself via the Knowledge
Forge's normal human-approved path. `probe/meridian.test.ts` pins their
presence, spec frontmatter and trigger sections.

## 2. The NATURA pass (applied from the skills)

- **Warmth & depth:** soft diffuse elevation, hover lift + deeper shadow,
  one-shot selection ring, slimmer scrollbars, warm selection ink.
- **Natural motion:** unified deceleration curve; pages settle and cards
  stagger (≤4); toasts settle; connected ports ring once; buttons press
  quietly; everything transform/opacity only, with an explicit
  `prefers-reduced-motion` kill-list (probe-visible).
- No palette change: the INK six (13.0.1) stay — this pass is frame, motion
  and craft.
