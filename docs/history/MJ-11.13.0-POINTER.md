# MJ 11.13.0 — THE DIFFERENTIATORS RELEASE (2026-09-07)

> 11.12.x made governance mechanical. 11.13.0 turns it into the pitch:
> budget authority (hard USD caps, not estimates), a proof dossier
> (one digest-stamped export of memory, beliefs, skills, the measured
> experiment and the ledger), and proof-of-learning inside that dossier.
> This is the first release whose headline features are market-facing
> rather than review-facing — and they land on the enforcement base
> 11.12.3 built.

The 11.13.0 release notes ship in upstream `docs/history/MJ-11.13-UPGRADE.md`
and the regenerated `verify/BUILD-INFO.txt`. This file is the discoverable
pointer in-repo; both ship with the source.

## What landed

- **Budget authority.** The root envelope carries `budgetUsd` — signed into
  the canonical digest, attenuated like every other power (children tighten,
  never loosen), refused pre-flight when exhausted, and checked by the
  executor against REAL charged spend after every wave. No further seat is
  invoked once the cap crosses. Runner UI exposes the cap (blank = uncapped).
- **Proof dossier (`src/mission/dossier.ts`).** One click on the Audit page
  exports a digest-stamped JSON: memories, beliefs, skills, the measured
  experiment, receipts, the live ledger — all derived at export time. Any
  edit after export breaks the digest (`verifyProofDossier`).
- **Proof-of-learning inside the dossier.** Strategy versions, adopted score
  and note, measured-run count. A reviewer can see what the system learned,
  not just what it did.
- Review nit: Settings palette count corrected to fourteen.
