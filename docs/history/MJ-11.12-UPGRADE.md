# MJ 11.12 — MOSAIC-Ω alignment upgrade notes

The user's MOSAIC-Ω composition (adaptive planning depth, belief tracking,
grounded simulation, process verification, causal memory, self-improvement) was
audited against 11.11.1 in `docs/MOSAIC-OMEGA-COMPAT.md`. The audit found nine
of fifteen stages already present in measured form and prescribed an extract,
not a rebuild. 11.12 ships that extract — and, per MJ's own rule that
predictions are not evidence, ships it as a MEASURABLE experiment arm so MJ
benchmarks the framework on itself.

## 1. Belief-state tracking (`src/mission/belief.ts`)

A world-belief store separate from the action policy (Agent-BRACE style).
Beliefs carry claim, class (known / probably / uncertain / contradicted /
unknown), confidence, source, timestamp, dependencies and evidence. Rules:
external claims cap at "probably" — only verified local execution may be
"known"; same-subject assertions from different sources that disagree become
"contradicted" and surface in briefings with a verify-before-acting warning;
predictions are labelled `[prediction — NOT evidence]`. Beliefs never enter
lesson memory, arm scores, or receipt measured facts. Measured run facts update
the store at settlement.

## 2. Proof-carrying actions (`src/mission/actionPacket.ts`)

Every runner-launched mission travels with a signed Action Packet: intent,
belief digest, plan step, prediction, risk, permission, rollback, verification
condition — SHA-256 canonical digest + Ed25519 where available, same pipeline
as the receipts. The executor checks `packetAllowsExecution` BEFORE anything
runs or spends: refused packets abort; irreversible actions without explicit
"allowed" permission abort. The report carries the packet so outcomes bind to
intentions.

## 3. Causal memory edges (`src/mission/lessons.ts`)

Lessons now carry `causal` edges (decision / action / observation / outcome).
`retrieveCausal` answers "what happened when we tried X under similar
conditions" by matching over the causal chain — zero-overlap conditions
retrieve nothing, so there is no similarity bleed.

## 4. The framework measures itself (`src/mission/selfImprove.ts`)

StrategyParams gains a fifth dimension, `mosaic`: when the governing strategy
has it on, briefings include causal-memory and belief lines and runs carry
action packets; when off, they do not. Because runs are attributed to the
strategy that governed them (11.11.1), the online experiment directly measures
mosaic-augmented missions against baseline missions — MIN_TRIALS per arm,
strict margin, adopt or retire with the numbers on the Evolution page. The
"will the framework improve MJ" question is now answered by signed, attributed
runs, not by opinion.

## 5. Verification

New probe suite `probe/mosaicAlign.test.ts` (20 assertions) pins: external
claims never "known"; contradictions detected and surfaced; predictions
labelled and excluded from evidence; packet verification + tamper detection;
the mechanical execution rule; causal retrieval without similarity bleed; and
the mosaic dimension rotating through the experiment.
