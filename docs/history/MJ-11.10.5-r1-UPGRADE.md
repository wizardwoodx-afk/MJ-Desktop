## What changed in the re-cut

- **`probe/reviewVisibility.test.ts` is now hermetic.** The probe used to hardcode
  `master` as the base branch; `git init`'s default branch differs across reviewer
  environments (the exact fragility that made this path time out twice in independent
  runs). The base branch is now read from the repo, every git call sets
  `GIT_TERMINAL_PROMPT=0` and an empty `GIT_TEMPLATE_DIR` so nothing can prompt or
  inject hooks. Verified 36/36 under BOTH `init.defaultBranch=master` and
  `init.defaultBranch=main`.
- **Evidence-pack disclaimer states the review's caveats verbatim.** MJ is not
  "EU AI Act compliant" and is not a compliance product — it supports compliance
  work; applicability depends on system and use case. Provenance statements are
  MJ-specific provenance shaped on in-toto conventions — NOT SLSA certification.
