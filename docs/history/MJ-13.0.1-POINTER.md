# MJ 13.0.1 — the INK retune: unknown minerals on black

*Release pointer. Full notes live in the CHANGELOG row (13.0.1); this file
names what changed and where. This is the owner-review pass on 13.0.0: the
palette was judged "common" (warm-black + gold reads as the default premium
template) and the surface still felt like an engineering tool — cramped,
mono-shouting, restyled-but-not-redesigned nodes.*

## 1. The palette — INK (true black, unknown minerals)

The OBSIDIAN six retire for a set built on the owner's direction: **black
ground, minimal colours that are actually uncommon**. No gold, no brass, no
violet, no cyan, no neon.

| theme | ground | signal | character |
|---|---|---|---|
| `ink` | black `#000000` | **smoked apricot** `#C98A62` | flagship (default) |
| `pitch` | OLED black `#000000` | **dusty rose** `#BD8577` | |
| `slag` | graphite `#0B0C0E` | **whetstone** `#9AA6AE` | cool |
| `fern` | black-green `#070A08` | **seedpod olive** `#A79A63` | |
| `ivory` | paper `#F5F1E9` | **copper** `#A4502C` | light |
| `travertine` | stone `#EFE9DC` | **bronze-olive** `#7A6B3A` | light |

Old saved themes migrate by alias (obsidian→ink, onyx→pitch, hematite→slag,
peat→fern, …). Every secondary stays color-mix-derived from the five base
hues.

## 2. What "premium" changed here (the frame, not just the paint)

Live research on premium-perception was explicit: whitespace is the single
largest signal (studies: up to ~300% perceived-value lift), then type
hierarchy, then restraint. So 13.0.1 rebuilds the frame:

- **Copy reads as text, not telemetry.** `.muted` body copy moved from 9-11px
  monospace to 12.5px Inter; page subs from mono to 13px Inter; labels keep
  mono only where they are data.
- **Cards breathe.** Card padding 14×16 → 22×24, radius 14px, page gutters up.
- **Controls.** Buttons 8px radius with a quiet press state; inputs focus with
  an accent ring instead of a default outline.
- **The rail.** Nav labels are now 12.5px Inter/500 (normal case) with an
  active accent tick; icons quiet 15px.
- **Theme options in Settings** are real choices: each option is a row with a
  live two-tone preview (ground + signal swatch), name and descriptor.

## 3. Icons — the clean cut

The FOUNDRY facet chips (accent-filled squares on every glyph) are gone.
Every icon is now a uniform 1.6-weight stroke, round caps and joins, no
fills — 43 glyphs, one grammar.

## 4. Nodes — anatomy v2 (the actual redesign)

- Cards carry **live state on the frame**: running/error/done tint the border
  and the icon tile (running agent tiles glow in the signal and the spine
  pulses; reduced-motion kills the pulse).
- **Ports now sit ON the card edge** (half-straddling), so every wire lands
  visibly on its anchor; connected ports fill with the signal and wear a
  soft ring; valid targets pulse while linking.
- Purpose text clamps to two lines; the meta footer is one quiet,
  dot-separated line instead of chip clutter.
