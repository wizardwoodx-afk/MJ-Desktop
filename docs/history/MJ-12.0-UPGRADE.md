# MJ 12.0 — UPGRADE notes (the One-Engine release)

This file exists per the probe contract: every `MJ-x.y` release ships release
notes named `MJ-x.y-UPGRADE.md` (theme probe). Full release notes live in
`CHANGELOG.md` (row 12.0.0), `docs/history/MJ-12.0.0-POINTER.md`, and
`docs/INFORMATION-ARCHITECTURE.md`.

## What changed for the user

The app is now ONE product surface: **Mission Loop · Workflows · Proof ·
Audit · System**. Everything the pre-12.0 pages did is reachable through the
Mission Loop screen or one of the four other doors:

- Teams, self-evolution, the feedback loop, adaptive learning and agent
  communication are phases of one engine (COMPOSE → DISPATCH → COMMUNICATE →
  EXECUTE → GATE → ADAPT). The engine screen shows the crew, the live bus,
  the cycle ledger (one signed receipt per cycle), and the human gate where
  the loop's proposals wait for your decision.
- Old destinations (Home, Teams, Missions, Mission Control, Runs, Observe,
  Evolve, Connectors as its own page, …) are no longer navigable. The feature
  code remains in the tree where probes exercise it; nothing was deleted
  blindly, nothing ships as a second front door.
- System now groups Connectors / Providers / Browser / Preferences in one
  door.

## What changed under the hood

- `src/mission/missionLoop.ts` — the engine: one runtime that owns the whole
  cycle and folds every measured outcome through the same stores the product
  reads (team evolution, bandit/elastic, lessons, receipts).
- `src/app/nav.ts` — the map is the product (five doors, three groups).
- `src/domain/types.ts` — `PageKind` trimmed to the five doors.
- Probes: `navAlign` re-pinned (32/32); new `missionLoop` suite (56/56);
  totals 74 live suites / 73 offline bundles.

## If something does not behave

- A run that used to live on Teams → run it from the Mission Loop screen
  (same executor, same gates, same receipts).
- Anything the Evolve page used to show → the Loop screen's adaptation strip
  and human gate (same stores — the engine writes them now).

# MJ 12.0.1 — patch notes (appended to the 12.0 upgrade record)

The 12.0 review confirmed the engine fusion and flagged three open items —
12.0.1 closes them:

1. **Explicit human feedback is back inside the Loop.** Every cycle in the
   ledger carries a rating panel (1–5 + comment). Ratings go through the
   engine's `submitHumanFeedback()`: they queue on every seat that ran and
   the next fold turns them into evidence (1–2 = weight-2 `Human: …`
   evidence; 4–5 = praise suppression; 3 = neutral). Same pipeline the old
   Teams page used — now engine-owned and probe-pinned.
2. **The Loop page imports the engine only.** Crew persistence, host deps and
   the bus projection are engine API now (loadCrews/persistCrew,
   loopHostDeps, loopBusFeed). navAlign forbids agentTeam/hostDeps/
   interAgentChannel imports on the page.
3. **Precise claims.** The engine orchestrates the specialized engines of
   record; it is not one physical store. All 12.0 prose that implied
   otherwise was corrected and the wording is probe-pinned.

Totals: 74 live suites / 73 offline bundles (unchanged); missionLoop 67/67;
navAlign 39/39.
