# MJ 15.1.0 — UPGRADE: what is proven and what is not (ROGUE: the Vouch Cycle 2.0 runtime)

*The Teammate door becomes the ROGUE runtime — the accountable colleague,
built fully. Same door, same engine rule, a complete cycle.*

## What changed

1. **The Vouch Cycle 2.0** — `src/mission/teammate.ts` is upgraded from
   "a seat with tools" to the full runtime:
   - **ROUTE** — dual-process: every run is triaged into a **fast path**
     (recall → act → vouch) or a **slow path** (full plan → simulate → gate)
     by risk + step count + mode; the choice and its reasons are shown in
     the trace and minted into the receipt.
   - **RECALL** — facts, matched learned preferences, and available skills
     are pulled before reasoning; what was pulled is recorded in the
     receipt's session event.
   - **SIMULATE** — risky actions (workspace writes, mission dispatch) are
     **dry-run before the human gate**: ROGUE signs a prediction
     ("what will exist when this is done", side effects, warnings,
     confidence). Overwrites and "no crew" states are surfaced as warnings.
     VOUCH then checks **prediction vs. reality** and the receipt records
     `matched` / `diverged` per action and in the verdict.
   - **LEARN** — fully successful runs distill **test-gated skills**
     (name, trigger, steps, tool, provenance = the receipt). A candidate
     with an unknown tool or a failing replay is **rejected into failure
     memory** — self-learning that cannot regress. Skill re-verification
     bumps the version; runs/wins accumulate.
   - **Feedback bound to receipts** — 1–5 + note, stored on the receipt,
     classified into a failure mode (unsafe / incorrect_result / slow /
     tone / other); an unsafe report or avg ≤ 2 **flags the skill** for
     human review. No vague thumbs-up; the feedback names the exact run.
   - **Threads** — conversations are threads; a new thread drops the
     previous one; **"continue <thread>"** resumes a dropped thread with
     its real context. No match → the real thread list, honestly.
   - **Preferences** — "from now on: …" learns a standing preference
     (visible, deletable, applied in RECALL, labeled in the trace).
   - **Live web evidence** — the `web_search` tool runs MJ's keyless
     web-evidence layer (Wikipedia, HN, GitHub; optional self-hosted
     SearXNG/Brave). Source kind is stated on every hit; provider failures
     are reported, never hidden.
   - **Inspectable memory** — `exportTeammateMemoryMarkdown()`: facts,
     preferences, skills, failure memory, workspace, threads — one local
     Markdown document you own.
2. **Receipt protocol extension** — `teammate.simulation` events;
   `route`, `prediction`, `skillId` fields on session/verdict;
   `simulated` + `predictionMatched` on action events. Same
   mj-proof-receipt/2 chain/seal/signature rules; verifier unchanged.
3. **The page** (`TeammatePage.tsx`) — thread strip, FAST/SLOW + RECALL +
   SIMULATE trace cards, feedback stars bound to each receipt, memory rail
   with FACTS/PREFS/SKILLS/FAILURES tabs + Markdown export. It still imports
   ONLY `mission/teammate.ts` (the engine rule, pinned).
4. **`probe/teammate.test.ts`** — grows from 16 to 33 assertions: dual-path
   routing, simulation (new-file clean, overwrite warned, matched/diverged
   predictions in real receipts), the test gate (unknown tool rejected,
   failing replay rejected, both into failure memory), feedback → flagged
   skill, threads + dropped-thread continuity + honest no-match,
   preferences, and the memory export.
5. Version bumped to 15.1.0 across all six pinned manifests (versionDrift
   enforces); offline verification pack rebuilt byte-pinned.

## What is proven (the gates, re-run against this tree)

- `tsc --noEmit` — zero type errors.
- `npm test` — 82 live suites, including the grown `teammate` probe:
  routing (fast vs slow, probe-verified in real receipts), SIMULATE
  (signed predictions; overwrite warnings; `matched` on approved writes,
  `diverged` on denied writes), LEARN (skills minted with provenance;
  unknown-tool and failing-replay candidates rejected into failure memory;
  feedback classified and bound to the receipt; flagged skills), threads
  (drop, resume, honest no-match), preferences, and the Markdown export.
- The offline verification pack is rebuilt byte-pinned; `node verify/run.mjs`
  re-runs the whole pack with zero MJ state.

## What is NOT (yet) — the honest gaps

- **The brain is still simulated.** 15.1's decisions are offline,
  rule-based, and labeled as such in the UI and in every receipt
  (`brain: simulated`). The `TeammateBrain` seam is unchanged: a
  model-backed brain (local-first via the provider registry, hosted keys
  after) plugs in with zero page changes — 15.2 scope.
- **No council yet.** THINK is single-brain in 15.1. The council mode
  (heterogeneous models deliberating, the deliberation itself vouched)
  rides the harness registry and is 15.3 scope, with multi-bot +
  senior/junior mentoring alongside it.
- **No proactivity yet.** ROGUE answers; it does not yet run scheduled or
  triggered work on its own (15.2: schedules + triggers, every proactive
  act vouched, mutable by the user).
- **No hands yet.** Browser use and computer use need the Tauri native
  layer (Rust on the user's machine); they land in the native phase,
  every action receipted. The web build honestly reports when web
  providers are unreachable — it never fakes evidence.
- **The self-upgrade meta-loop is the final gated feature.** The substrate
  is in place (skill library + failure memory + the receipt chain), but
  ROGUE does not yet propose changes to its own control logic. When it
  ships: independent evaluator, non-divergence guard, protected components
  (its own evaluator/audit/signatures/shutdown stay out of its reach),
  owner approval, and every self-upgrade vouched, versioned and reversible.
- **The workspace is a local file store, not the OS file system** (unchanged
  from 15.0, still labeled). Real OS-level tools land with the native phase
  under the Tauri permission model.
- **Dispatch needs a composed crew** (unchanged) — with no crew it refuses
  honestly, and 15.1's simulation now tells you *before* the gate.
