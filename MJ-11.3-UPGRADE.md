# MJ 11.3 — THE INSCRIPTION PASS

V11.2 shipped the INSCRIBED token system and then left the house half-painted: the
probe suite was failing, the base stylesheet still carried the retired amber heritage
palette in a dozen hardcoded hexes, the fonts the theme asked for were never actually
declared, and a micro-interaction block (spring curves, glow shadows, scale-on-hover)
contradicted the design language every document in this repository promises.

V11.3 finishes the sentence. One design language, stated once, obeyed everywhere.

---

## 0. The failing probe is green again

`theme.test.ts` failed on the V11.2 tree with a precise complaint:

```
FAIL the legacy nothing.css design-language file is gone (replaced by themes.css) — still exists
```

`src/styles/nothing.css` was superseded by `themes.css` in V11.2 but never deleted —
and never imported by anything (verified: zero references in `src/`, `index.html`, and
the build graph). Deleted. **All 37 probe suites now pass.**

## 1. The base stylesheet stops fighting the theme system

`mj.css` still hardcoded the pre-V10 amber scheme (`#c9a66b` and friends) in exactly
the places the V10.1 probe history warns about — "hardcoded hex survived in
TypeScript" was the original bug class, and the CSS had its own survivors:

| Surface | Before (hardcoded) | After (token) |
| --- | --- | --- |
| canvas dot grid | `rgba(201,166,107,…)` | `var(--dot-1)` / `var(--dot-2)` |
| idle wires | `rgba(201,166,107,0.38)` | `var(--wire)` |
| active / streaming / done wires | amber literals | `var(--wire-active)` / `--wire-hot` / `--wire-done` |
| ETA segment track | `#1c1c1c` | `var(--seg-off)` |
| glyph status lights | `#2a2a2a` | `var(--glyph-off)` / `--glyph-on` |
| empty-canvas wordmark | `#1c1c1c` | `var(--inset)` |
| scrollbar thumb | `#222` | `var(--scroll-thumb)` (+ accent hover) |
| macOS traffic lights | beige/olive trio | monochrome; only **close** carries signal red |

Every palette now paints every surface. The `:root` fallback palette itself was
re-derived from `inscribed` (OLED black `#000000`, white data, `#D71921`), so the
pre-theme boot flash is the design language instead of a ghost of V9 — and the
anti-flash boot script in `index.html` no longer has anything wrong to flash.

## 2. The fonts the system names are the fonts that load

`themes.css` has requested `"Space Mono"` and `"Space Grotesk"` since V11.2. Neither
was ever `@font-face`-declared, so every `--font-mono` surface silently fell back to
JetBrains Mono and Space Grotesk never rendered at all. The woff2 files were already
bundled in `src/assets/fonts/` — declared now:

- **Space Mono** 400/700 — the instrument voice (labels, numbers, ALL-CAPS metadata).
- **Space Grotesk** variable 300–700 — declared as the grotesque fallback.
- **Inter** 400/500/600 — leads `--font-ui`. The clean sans. Nothing OS pairs a clean
  grotesque body with its dot-matrix display face; Inter is that body here.
- **Doto** variable 100–900 — unchanged: the one hero face (wordmark, clock, hero
  numbers), still wired through `--font-doto` and still probe-verified on disk.
- **JetBrains Mono** — stays in the stack for long code blocks, where it reads better
  at 10–11px.

The type contract is now three jobs / three faces: **Inter for content, Space Mono for
markings, Doto for the hero moment.**

## 3. The dot system

The dot is the atom of the Nothing OS inscription; V11.3 makes it a real primitive set
(shared `:is()` rules in `themes.css`, no new tokens, no per-theme copying):

- **Status pills lead with a 4px dot** (`::before`, `currentColor`) — every pill in the
  app now reads as an instrument lamp, not a label with a border.
- **Checkboxes are mechanical switches** — square 28×14 track, square thumb, hairline
  borders, percussive `--t-fast` travel; the thumb fills with the accent signal when
  on. No border-radius, no glow.
- **Sliders end in a dot** — 2px hairline rail, 10px accent dot thumb.
- **Theme chips carry their own pigment** — the Settings theme row is now six chips,
  each with a dot in that palette's own accent (hex lives in CSS, the token home —
  never in TypeScript, per the original probe's rule).
- **Focus is a hairline ring** — 1px solid accent at 2px offset, never a glow.
- **`.dot-rule`** — a dotted hairline divider utility.

## 4. Motion: percussive, not fluid

The V11.x micro-interaction block spring-scaled buttons on press, lifted tabs on
hover, scale-bounced pills, and pulsed a red glow — every one an anti-pattern the
INSCRIBED header explicitly bans ("no shadows, no blur, no spring easing"). Replaced:

- No `transform` on hover/active anywhere in the chrome. State reads through
  **borders, colour and opacity** on the system's fast ease-out.
- `button:active` breaks its border to the accent instead of shrinking.
- `.card.selected` marks with an inset 2px accent bar instead of a glow shadow.
- `mj-glow-pulse` and `mj-beacon` keyframes deleted (unused); `mj-pop` and
  `mj-enter-fade` survive as opacity-only steps.
- Shape follows the system everywhere in the base sheet: radius 0/1/2, motion
  90/140ms ease-out.

## 5. Housekeeping

- `fonts.css` header no longer references the retired `nothing` theme.
- Settings header line names the real type stack (Inter / Space Mono / Doto).
- Version 11.3.0 across `package.json`, `package-lock.json` (both spots),
  `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`, `src/version.ts`, and the four
  doc titles the versionDrift probe checks.
- Rust: **untouched in this pass.** The sandbox that produced this release has no
  cargo/GTK toolchain, so per the honesty rules no Rust line was edited without a
  compiler to check it. CI (cargo check on linux/macos/windows) still gates every
  push; the known `unwrap()` density in `control_mcp.rs` is logged in
  `LOCAL-WORKLIST.md` as debt, not silently "fixed".

## 7. Not proven — unchanged

The honesty ledger does not shrink because the CSS got tidier: no real mission ran
against a real coding CLI to produce this release; the theme probe proves tokens and
wiring, not taste; and one dot-matrix font cannot make a monochrome out of a product
that has not yet shipped to a stranger.
